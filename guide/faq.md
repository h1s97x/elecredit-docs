# 常见问题

## 凭据与认证

### 为什么一直返回 `SYS005 余额不足`？

**因为你的接入是对的。** `SYS005` 意味着签名已通过签名校验、凭据有效、网关可达，
只是账户余额不足。去 <https://api.elecredit.com/admin> 充值后即可拿到真实数据。

不要把它当认证失败去改签名——那是新手上手最常见的无效排错。

### 我有 API Key，能用吗？

不能。Elecredit 用的是 **App ID + App Key 二元组**，不是单一 API Key。
两者必须同时配置才生效。

### 报 `SYS001 签名校验失败`，怎么快速定位？

按这个顺序检查（覆盖 90% 的场景）：

1. **body 是紧凑 JSON 吗？** `{"entName":"贵州茅台"}` ✅ / `{"entName": "贵州茅台"}` ❌
2. **中文转义了吗？** 必须 `ensure_ascii=False`，不能出现 `\u8d35...`
3. **时间戳是毫秒吗？** `int(time.time() * 1000)`，13 位
4. **签名和发送的是同一个 body 字符串吗？** 若序列化了两次，很可能不一致

详细排查见[签名算法](./signature)。

### `SYS002 请求过期` 怎么办？

时间戳必须是**毫秒**（不是秒）。同时确认本机时钟同步（容器里常见时钟漂移）。

## 数据与参数

### 为什么传了企业名却返回 `001 查询成功无结果`？

`001` 是**正常业务响应**，表示查询成功但没有匹配数据。可能原因：

- 名称不是工商登记全称（先用 A07 模糊查询拿到准确全称）
- 该企业确实没有对应记录（例如从未被行政处罚）

### 为什么 `entName` 传了却报 `400 企业信息不能为空`？

**参数名写错了。** `B04 招投标` 与 `P0020019 实控人` 必须用 `entInfo`，不是 `entName`。
这个错误是长期存在的坑，两端都已修正。

### 为什么 `/saic/SaicinvWh` 报 `SYS044 资源不存在`？

**路径大小写敏感。** 可用的是**小写 w**：

- ✅ `/saic/SaicinvWh`
- ❌ `/saic/SaicInvWh`

注意 `SYS044` 与「路径确实不存在」同码，极易误判成路由问题。

### 司法查询能一次拿多个 `type` 吗？

不能。`D11` 的 `type` 是**单值、大小写敏感、不支持逗号多选**。
一次拿多种类型只能逐类型调用（fan-out）。

- 只想看「各类型有多少条」→ Python SDK 的 `judicial_summary()`，1 次调用
- 要「每个类型都有代表记录」→ `judicial_all()`，自动跳过空类型、自动夹紧页数

### `D11` 的 `range` 设成 50 为什么报 `999 系统异常`？

`range` **上限 20**（默认 10）。超过会硬失败返回 `999`，不是静默截断。
同理 `pageNo` 超出总页数也报 `999`。

## 结果处理

### `resultData` 里面为什么还有一层 `P0010068Data`？

上游会把业务体再包一层：`resultData = { "<产品码>Status", "<产品码>Data" }`，
**产品码每个端点都不同**。

Python SDK 用 `product_payload()` 自动探测，上游换码也不会失效；
其它语言按 `resultData["<产品码>Data"]` 取，对照表见 [API 参考总览](../api/#resultdata-包裹结构与产品码)。

### 图谱（F09）请求很久没返回，是失败了吗？

不是。`F09` 的**超时是 60 秒**（其它端点默认 10 秒），深层穿透数据量很大。

建议：

- 客户端超时设置 ≥ 60s
- 用 `--output <file>` 把结果落盘，不要试图打印到终端
- 用 `--level` 控制递归层数（默认 3 层、5% 持股阈值）

### 结果太大，终端被刷屏 / 被截断

大结果必须落盘：

```bash
elecredit enterprise graph --ent-info 贵州茅台 --level 4 --output graph.json
```

落盘后只汇报**路径、行数和摘要**。Agent 场景尤其如此——
不要把全量 JSON 塞进对话上下文。

## 接入方式选择

### CLI 和 SDK 覆盖的端点一样吗？

完全一样，都是 10 个。不存在「CLI 能做、SDK 不能做」的差异。
选哪个只取决于你的场景：

| 场景 | 选它 |
|---|---|
| 终端、CI、Agent | [Node.js CLI](./node-cli) |
| 数据分析、服务集成 | [Python SDK](./python-sdk) |
| 任何其它语言 | REST 直连 + 自行 MD5 签名 |

### 能在浏览器里直接调吗？

**千万不要。** App Key 必须只在服务端使用，注入浏览器端 bundle 等于公开泄漏。
正确做法是服务端中转（见代码仓库的 `examples/nextjs/`）。
